# EcoVault

EcoVault adalah layanan pengelolaan sampah terintegrasi yang dirancang untuk membantu masyarakat mengelola sampah dengan lebih mudah, bertanggung jawab, dan berkelanjutan. Proyek berisi tampilan frontend tanpa logic backend yang terdiri dari fitur pemesanan penjemputan sampah serta sarana edukasi publik mengenai pentingnya pengelolaan sampah dan pelestarian lingkungan. EcoVault terdiri dari dua bagian utama:
- **Website pengguna**, yang memungkinkan pengguna memperoleh informasi, mempelajari edukasi lingkungan, dan mengajukan layanan penjemputan sampah.
- **Dashboard admin**, yang digunakan untuk mengelola konten edukasi, informasi layanan, serta data yang berkaitan dengan operasional platform.

EcoVault dikembangkan menggunakan:
- HTML
- CSS
- JavaScript
- Bootstrap
